# Contributing

[CONTRIBUTING.md](https://github.com/brnrhq/brnr/blob/main/CONTRIBUTING.md) says how to build, test and propose a
change, including the [requirements for acceptable contributions](https://github.com/brnrhq/brnr/blob/main/CONTRIBUTING.md#requirements-for-acceptable-contributions)
and [coding standards](https://github.com/brnrhq/brnr/blob/main/CONTRIBUTING.md#coding-standards).
brnr has five direct dependencies; CI checks their licenses and
advisories with cargo deny, and with cargo vet that every crate is audited
(by Mozilla, Google and others whose audits brnr imports) or listed as an
exemption still to audit. The [audit status](https://github.com/brnrhq/brnr/blob/main/supply-chain/README.md) records
the remaining work; an exemption is not an audit. Report vulnerabilities privately, as
[SECURITY.md](https://github.com/brnrhq/brnr/blob/main/SECURITY.md) says.
